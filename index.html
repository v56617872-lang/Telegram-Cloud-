Точка старта берётся из закрытия 1‑минутной свечи OKX (history‑candles). История для графиков — часовые (1H) свечи от точки старта до текущего момента; текущая цена дополняется live‑потоком (WebSocket ticker). Прокрутка колеса над любым графиком сдвигает точку старта на 1 час вперёд/назад и полностью пересчитывает оба графика.

API и авто-торговля

Ключи бирж и автоматическое открытие/закрытие по уровням Alerts — тестируйте на малой сумме
⚠️ Прежде чем включать
Ключи хранятся только в памяти этого браузера (localStorage на этом устройстве) и уходят напрямую на API биржи — больше никуда. Создавайте ключ с правами только «Trade» (без вывода средств), включите привязку по IP, и начните с минимального размера ордера. Это не финансовая рекомендация — решение и риск на вас. Приватные торговые запросы должны отправляться напрямую из браузера на OKX/Bybit; если биржа заблокирует запрос политикой CORS, потребуется собственный сервер-прокси — в консоли браузера будет видна ошибка.
